指向任意一个 Ming-3.0-tts 网关实例，设置仅保存在当前浏览器。

这个页面是 HTTPS，怎么连 http:// 网关
  1. 最省事：直接打开网关自带的页面 http://<网关IP>:8081/studio/ —— 同源，不用任何设置。
  2. 想继续用这个页面：点地址栏左侧的图标 → 网站设置 → 把「不安全内容」设为「允许」→ 刷新本页，再回来填地址。

网关默认已放行跨域（allow_origins=*）；换成自定义域名时记得同步。

关于演示模式

页面无法连接 API 时会自动切换为演示模式，使用仓库内置的示例音频。填写可用地址并保存后即可恢复完整功能。
